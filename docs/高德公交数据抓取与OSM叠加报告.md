# 高德公交数据抓取与 OSM 叠加报告

日期：2026-10-20  
项目：武汉个性化等时圈与区位评估平台  
数据范围：武汉市公交线路（公共数据线路清单 + 高德当前线路/站点）

## 一、最终覆盖

| 项目 | 数量 |
|---|---:|
| 公共数据线路 | 694 |
| 高德可用线路 | **591** |
| 覆盖率 | **85.2%** |
| 无 POI | 43 |
| 无线路 ID | 60 |
| 路线方向 | 1,054 |
| 线路站记录 | 27,303 |
| 空间站点簇 | 7,823 |
| 公交相邻站边 | 26,248 |
| 实际线路几何方向 | 1,124 |
| 线路几何坐标点 | 414,038 |

说明：

- 一个公共线路可能对应高德的两个方向或多个变体，所以“路线方向”和“实际线路几何方向”大于 591；
- 站点按“高德站点 ID + 100 米空间聚类”生成空间站点簇；
- 1,156 个原始站点 ID 存在同一 ID 对应多个物理位置的情况，已拆分为多个站点簇。

## 二、缺失线路

103 条线路未进入最终网络，主要类别：

| 类型 | 数量 |
|---|---:|
| 夜行线 | 17 |
| P 字头郊区线 | 22 |
| 区间线 | 2 |
| 其他普通线路/郊区线 | 62 |

其中：

- `no_poi`：43 条，高德 POI 搜索没有找到可用站点；
- `no_line_id`：60 条，找到站点但无法匹配到高德线路 ID。

缺失集中在黄陂、新洲等远城区和夜行线。高德对这些线路的覆盖不完整，暂不强行用错误匹配补齐。

## 三、站点与 OSM 吸附质量

| 指标 | 结果 |
|---|---:|
| 站点簇总数 | 7,823 |
| 武汉范围内 | 7,732 |
| 武汉范围外 | 91 |
| 吸附中位数 | **2.9 米** |
| 吸附 90 分位 | **11.1 米** |
| 吸附 95 分位 | 335.3 米 |
| 吸附平均值 | 67.0 米 |
| 最大吸附距离 | 3,505.9 米 |
| 吸附 ≤80 米 | 7,351 |
| 吸附 >80 米（低质量） | 472 |
| 吸附 >500 米 | 347 |

结论：

- 中心城区站点与 OSM 道路对齐良好，中位误差不到 3 米；
- 远城区部分农村站点附近没有 OSM 可行驶道路，吸附距离达到数百米甚至数公里；
- 这些站点保留原始坐标，并在 `snap_quality=low` 和 `flags=snap_gt_500m` 中标记，不应直接用吸附后的坐标做步行接驳。

## 四、线路边质量

| 指标 | 结果 |
|---|---:|
| 相邻站边 | 26,248 |
| 边距离中位数 | 约 525 米 |
| 边距离 95 分位 | 约 1,351 米 |
| 边 >3 km | 248 |
| 边 >5 km | 69 |
| 边 >10 km | 24 |
| 最大边距离 | 47.7 km |

最长边主要出现在：

- 新洲—汉口方向的快速/远郊线路；
- 黄陂旅游线、长距离郊区线；
- 部分线路首末站之间没有中间站。

这些长边不一定是错误，可能是快速线路的真实站间距离。已在 `amap_bus_edges.csv` 中用 `leg_gt_3000m`、`leg_gt_5000m`、`leg_gt_10000m` 标记，后续可按需要过滤。

## 六、时刻信息

当前数据还包含高德的 `timedesc`：

- 首末班时间；
- 高峰/平峰发车间隔；
- 夜行线定点发车时刻。

但它不是完整 GTFS 时刻表，没有每一班车在每个站的到发时刻。可用于：

- 按运营时间过滤线路；
- 用高峰/平峰间隔估算平均候车时间；
- 夜行线按定点发车近似。

不能用于：

- 逐班次公交路径规划；
- 精确到站时刻；
- 实时车辆位置和延误。

## 七、建议的下一步

1. 以 591 条线路为当前可复现公交网络，103 条缺失线路在说明书中标注覆盖缺口；
2. 用 `amap_bus_edges.csv` 构建公交图：
   - 边权 = 站间距离 / 平均速度 + 停站时间；
   - 换乘边按同站或 50 米内站点连接；
   - 候车时间用 `timedesc` 的高峰/平峰间隔，缺失时用固定值；
3. 将站点接入 OSM 步行网络：
   - `snap_quality=high` 的站点使用吸附点；
   - `snap_quality=low` 的站点使用原始坐标并标记，不强行接到几公里外的道路；
4. 生成 15/30/45 分钟公交+步行等时圈；
5. 对 103 条缺失线路，后续可用天地图或公共数据平台补，不影响当前网络骨架。

## 八、结论

当前已经形成一套可复现的武汉公交网络数据：

- 591 条线路；
- 7,823 个空间站点；
- 26,248 条公交边；
- 1,124 条实际线路走向；
- 站点与 OSM 道路中位吸附误差 2.9 米。

数据质量足以支撑首版公交+步行等时圈原型。主要限制是远城区 POI 覆盖和 103 条缺失线路，必须在使用说明和答辩中明确，不能把 591 条线路表述为武汉全部公交。
