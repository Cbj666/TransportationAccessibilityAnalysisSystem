## 写法约定

- 结论先写，数字必须有出处（脚本名 / 文件名 / 字段名）；
- 路径写相对仓库根目录的形式，例如 `data/processed/v1/stops_bus.csv`；
- 提到限制就写清楚"不能说什么"（例：不能说 591 条是全部公交）。
